# Premium green app-wide redesign

## Goal
Unify Tribhashniya as one premium green education product across teacher, institute, parent, student-facing learning, authentication, onboarding, and shared system screens without changing existing behavior.

## Visual direction
- Use the selected Emerald academic composition, adapted to the locked mint-led palette and Outfit/Figtree typography.
- Deep green provides navigation and primary actions; emerald marks interaction; mint and sage support content; warm cream and white provide breathing room; amber and coral remain status-only.
- Use a stable deep-green sidebar, clean white topbar, guided card grids, 18–24px card radii, subtle borders and shadows, and restrained micro-interactions.

## Implementation
- Replace the global color, typography, radius, shadow, focus, motion, chart, blackboard, and role-tone tokens in the shared stylesheet.
- Upgrade shared cards, metrics, badges, progress, buttons, forms, empty states, onboarding, navigation, dialogs, drawers, and status treatments so every existing page inherits the system.
- Refine the teacher Home hierarchy, classroom cards, planner, plan output, assessments, progress, resources, translation, language, offline, notification, and settings presentation.
- Apply the same system to institute and parent screens, with denser institute information and softer parent-facing emphasis.
- Style the existing learner-facing experience as the student visual language; do not invent a new authentication role or backend workflow absent from the current application.
- Preserve Live Class ordering, its two translation panels with all four modes, teaching tools, understanding, End Class, and the visually distinct chalkboard.
- Redesign welcome, login, role selection, and onboarding using the same brand system.

## Verification
- Check every route for shared styling and required page metadata.
- Verify representative teacher, classroom, Live Class, planner, institute, parent, learner, settings, and authentication screens on desktop and mobile.
- Confirm navigation, drawers, translation modes, forms, AI previews, and existing role workflows still function.
